The command palette puts everything Switchboard can do one search away. It lists the commands that fit where you are, jumps to any session or project, and starts a new session without leaving the keyboard.

<Screenshot name="palette" alt="The command palette open over the main window, listing commands grouped under This session and Git, each with its icon and shortcut" eager />

## Open it

| Press | What opens |
|---|---|
| <Kbd shortcut="palette.commands" /> | The commands |
| <Kbd shortcut="palette.goto" /> | Go to a session or project |

In the terminal, <Kbd keys="mod+k" /> clears the terminal, so use <Kbd keys="mod+shift+p" /> there. Pressing the other shortcut while the palette is open switches it in place. <Kbd keys="escape" /> closes it.

## Prefixes

What you type first decides what the palette lists, as in VS Code:

| Type | Lists |
|---|---|
| (nothing) | Go to a session or project (<Kbd shortcut="palette.goto" />) |
| `>` | Commands (<Kbd shortcut="palette.commands" first />) |
| `+` | New session in a project: goes straight to picking a project |
| `!` | The project actions of the session you have open, to run one |
| `?` | Help: these prefixes, and the keyboard shortcuts sheet |

<Kbd keys="backspace" /> in an empty field leaves a prefix and goes back to Go to.

## Go to a session or project

With nothing typed, Go to lists your sessions under the sidebar's own headings, in its order: Needs you, Working, Pinned, Today, Yesterday, Earlier. Unsent messages come first. It can stand in for the sidebar while that is closed. Type a few letters to match session titles and project names; projects follow under **Projects**.

- <Kbd keys="enter" /> opens the session. On a project, it starts a new session there.
- <Kbd keys="alt+enter" /> opens the session beside the current one, in [split view](/sessions/split-view/).

## Commands

With nothing typed, the commands for where you are come first, in groups:

- **This session**: the session you have open.
- **Git**: when its folder is a git repository.
- **Project actions**: the session's project actions, as *Run: &lt;action&gt;*.
- **Terminal**: while the terminal panel is open.
- **Split view**: with two sessions side by side.
- **New session**: while New session is open.
- **Settings**: while Settings is open, to go to a section.

Then **Recently used** (the last five commands you ran in this window), then the rest under **Commands**. Type to search: the palette matches titles, and a few other words each command answers to (*Archive* also answers to "done", *Change model…* to "opus"). A command only shows when it can run; nothing is ever listed greyed out.

Each row shows the command's shortcut, when it has one, so the palette also teaches you the keys.

## Steps

A command whose title ends in **…** asks for more: picking it shows its next step, and the command becomes a chip in the field. *Change model…* lists the models, *Fork session…* the messages to fork from, *Focus limit: set limit…* the numbers. In a list, <Kbd keys="mod+1..9" /> picks a row by its number.

<Kbd keys="backspace" /> in an empty field goes back one step, with what you had typed there.

### Start a new session

*New session…* (or `+`) ends in a small New session form:

<Steps>

1. Pick a project. Type to filter, or press <Kbd keys="mod+1..9" />. <Kbd keys="alt+enter" /> picks it in a [new worktree](/new-session/worktrees/), and <Kbd keys="mod+o" /> chooses any folder.
2. Write the prompt. The form has the route (current checkout and branch, or a new worktree) and the profile, model, effort and mode chips, starting from the project's defaults. Click the project to pick another one; the prompt comes along.
3. Press <Kbd keys="mod+enter" /> to start.

</Steps>

| Key | In the prompt step |
|---|---|
| <Kbd keys="mod+enter" /> | Start the session |
| <Kbd keys="mod+shift+enter" /> | Add the prompt to the [queue](/new-session/queue/) |
| <Kbd keys="mod+e" /> | More options: move the prompt and choices to the full [New session](/new-session/form/) view |
| <Kbd keys="backspace" /> | Back to the project list |
| <Kbd keys="escape" /> | Close; the prompt is kept as the project's unsent prompt |

## Settings

*Project order* in [Settings → General](/settings/#general) sets how the palette lists your projects: most recent first, or in your order.
