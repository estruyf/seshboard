A session shows its conversation with Claude, with the message box at the bottom. You chat as you would in the terminal, with streaming replies, `/` commands, `@` mentions and images, and you can follow every step Claude takes without the noise.

<Screenshot name="conversation" alt="A session's conversation: a summarised run of tool calls, a to-do list, Claude's summary with a code block, and the message box with its chips underneath" eager />

## Open it

Click a session in the [sidebar](/sessions/sidebar/), on [Home](/sessions/home/), or find it with <Kbd shortcut="palette.goto" />. Any past session works: type below it to continue it.

The header shows the title, the [state](/sessions/states/), the project and the branch. On the right are the **Changes** and **Terminal** toggles, the git button, **⋯** and the **×** that closes the session.

## Send a message

Type in the message box and press <Kbd shortcut="composer.send" />. <Kbd shortcut="composer.newline" /> starts a new line. In a list (`- `, `* ` or `1. `) it starts the next item, numbered one up; on an empty item it ends the list.

- **Commands and skills:** type <Kbd shortcut="composer.commands" /> at the start of the message for your commands and skills, your own included.
- **Side questions:** `/btw` and a question asks Claude about the session without adding it to the conversation, also while Claude works. See [Side questions](/sessions/side-questions/).
- **Mention a file:** type <Kbd shortcut="composer.mention" /> and pick a file from the list.
- **Code:** select text and type <Kbd keys="`" /> to wrap it as code: one line as `inline code`, several lines in a code block.
- **Earlier messages:** <Kbd shortcut="composer.history" /> at the start of your text brings back what you sent before. On the first line, the first <Kbd keys="arrowup" /> takes the caret to the start, and the next one brings the message back. Esc goes back to what you were typing.
- **Images:** paste them, drop them on the session, or click the image button under the message box. Images Claude reads or you attach show in the conversation.

### Context

Files you add as context show as chips above the message, each with a × to remove it. Claude gets them as references and reads them itself, so a large file stays small.

- Pick a file from the `@` list.
- Drop files and folders anywhere on the session. While you drag, the message box shows what a drop does: images are attached, other files and folders become context.
- Choose **Add context** (<Kbd shortcut="composer.add-context" />, the paperclip, or *Add context…* in the command palette) to pick several files at once: <Kbd keys="space" /> picks, <Kbd keys="enter" /> adds. The list shows the files of the session's folder. For a file somewhere else, click **Choose in <Os mac="Finder" windows="File Explorer" />…** next to the search field and pick it there. On macOS you can pick folders there too.

With the [VS Code companion](/vscode-companion/) you can send the lines you have selected in VS Code, problems and terminal output as chips too.

### Pasted text

When you paste a long text (more than 2,000 characters or 25 lines), it goes in a **Pasted** card above the message instead of in the box, so the box stays quick and your own words stay easy to read. The card shows the first lines; hover it for its size.

- Click the card to read or change the text. **Save** (<Kbd keys="mod+enter" />) keeps your changes, **Remove** takes it out.
- Hover the card and click × to remove it.
- Claude gets the text after what you typed, under its label ("Pasted text", "Pasted text 2"). It stays with an unsent message, also after a restart.

A message holds up to 1,000,000 characters. For a larger file, drop the file on the message box instead: Claude reads the parts it needs from disk.

### While Claude works

Replies stream in as Claude writes them. At the bottom of the conversation, the view follows the reply as it grows. Scroll up to read and it stays where you are; **New output below** takes you back to the end, which follows again (so does scrolling all the way down). When Claude is done, the button says **Jump to latest**.

You can keep typing while it works. What <Kbd keys="enter" /> does is your choice in [Settings, Conversation](/settings/#conversation), under **While Claude is working**:

- **Queue** (the default): your message waits in **Up next**, above the message box, and goes when Claude finishes the turn.
- **Steer:** Claude gets the message now and reads it at its next step. Claude isn't stopped.

The send button says **Queue** or **Steer** to match. Its ▾ menu has both, plus **Send now**. <Kbd shortcut="composer.send-other" /> does the one Enter doesn't.

- **Send now:** <Kbd shortcut="composer.send-now" />, or **Send now** in the ▾ menu, stops what Claude is doing and sends your message right away.
- **Stop:** press <Kbd shortcut="claude.stop" /> or click **Stop** to stop Claude. Esc doesn't stop Claude while a dialog, menu or list is open.

### Up next

Messages you queue stay above the message box, under the conversation, until their turn comes. They aren't in the conversation yet, so Claude hasn't seen them. One message goes each time Claude finishes.

- **Send now** on a message stops Claude and sends that message. The others keep waiting.
- Click a message, or press <Kbd shortcut="upnext.edit" /> on it, to edit it: it goes back in the message box. <Kbd keys="arrowup" /> in an empty message box does this for the last one.
- Drag a message, or press <Kbd shortcut="upnext.move" /> on it, to change the order.
- **Remove** (×, or <Kbd shortcut="upnext.remove" />) takes a message out. **Undo** in the toast puts it back.
- If you stop Claude, or a turn fails, nothing goes by itself. Up next says so and shows **Send next**. Sending a message yourself ends the pause.

Messages in Up next are kept when you look at other sessions, stop the session or quit Switchboard. A session that stopped shows them again, waiting: **Send next** or **Send now** brings the session back and sends, and so does a message of your own.

## Follow what Claude does

Each run of tool calls is one line, like Claude Code: what Claude is doing right now ("Reading src/app.ts…"), or what it did when the run ends ("Ran 3 commands and edited 2 files"), with how long it took. Click the line to see every step, and a step to see its details: diffs, command output, to-do lists and subagent runs.

- A **Tasks** pill above the message box shows Claude's to-do list ("Tasks 2 of 5"); click it to open the list.
- A green pill above the message box lists what runs in the background, such as a long command or an agent, with a way to stop each one.
- A file Claude names in a reply, such as `src/search/suggestions.ts:69`, is a link, and so is the **Show** or **Open** chip beside a tool run that read or changed a file. Click it to show the file in <Os mac="Finder" windows="File Explorer" />, where it is selected. <Kbd shortcut="transcript.file-link-other" /> opens it in your editor instead, at that line. Right-click it (or press <Kbd shortcut="context-menu" />) for **Show in <Os mac="Finder" windows="File Explorer" />**, **Open in** your editor and **Copy path**. If the file is gone, the link turns red and says so. To make a click open the editor, and <Kbd shortcut="transcript.file-link-other" /> show the file, change **Clicking a file link** in [Settings, Conversation](/settings/#conversation).
- Images in your messages show above the text, so **Show more** never hides them: one image at its own shape, two to four as thumbnails, and five or more as tiles with +N for the rest. Hover one for its type, size and pixel size.
- Images open full size with a click. <Kbd keys="arrowleft|arrowright" /> (or the filmstrip at the bottom) step through all of a message's images.

Prefer to see each tool call as its own card? Choose **Every step** in [Settings, Conversation](/settings/#conversation).

### Code blocks

Hover a code block in Claude's reply for its buttons:

- **Copy** copies the code.
- **Run in terminal** (on shell code blocks) types the command into a terminal tab of the session and runs it. For a block that shows a terminal session (`$` lines with their output), only the `$` lines run.
- A markdown block (a README, a pull request description) opens rendered, with a **Preview | Source** switch above it. Copy still copies the markdown.

### Save an image

Use the save button on an image, right-click it and choose **Save image…**, or press <Kbd keys="mod+s" /> while it is open full size.

## Change the model, mode and effort

The chips under the message box show the session's settings. Click one to change it while the session runs:

- **Profile:** the [Claude profile](/settings/claude-profiles/) the session uses, with more than one.
- **Model:** the model for the next messages. Also *Change model…* in the command palette.
- **Effort:** how hard Claude thinks, from **Low** to **Max**, or **Default**. Only for models that support it. Also *Change effort…*.
- **Mode:** the permission mode: **Ask before edits**, **Accept edits**, **Plan mode** or **Auto mode**. <Kbd shortcut="mode.cycle" /> switches between Ask before edits, Accept edits and Plan mode, like Claude Code. Also *Change permission mode…*.

In a narrow pane the chips get shorter (effort and mode show only their icon) instead of cutting words off.

### Context window and usage

Under the message box, a line shows your plan usage (your 5-hour and weekly limits; hover for when they reset) and a ring for how full the **context window** is. Click the ring to see what fills it, like `/context`, and **Compact now** to compact the conversation. *Compact context* in the command palette does the same.

After a compaction the whole conversation stays: a *Conversation compacted* line marks each place it was compacted, and you can scroll back past it.

## The hover toolbar

Hover over a message for its toolbar:

- **On your prompts:**
  - **Undo file changes since this message.** You see which files would change first, then confirm with **Undo changes**. Files go back to how they were before this message; the conversation stays as it is.
  - **Edit and resend.** Opens a new session with the conversation up to just before this prompt, and your prompt in its message box to change and send. The original session stays as it is.
  - **Copy message**, as you typed it.
- **On Claude's replies:**
  - **Fork from here.** A new session with the conversation up to this message.
  - **Copy as Markdown.**
- **On both:** **Remember this…** (the brain button) saves the message as a memory. See [Remember this](/memory/adding-memory/#remember-this).

You can also select text in any message and press <Kbd keys="mod+c" />. A toolbar shows above the selection with **Quote**, **Copy** and **Remember this…**. Press <Kbd keys="tab" /> to reach it from the keyboard, <Kbd keys="arrowleft|arrowright" /> to move between its buttons, and <Kbd keys="escape" /> to close it. The command palette has *Fork session…* and *Rewind to a message…* to pick a message from a list, and *Copy last reply*.

To save part of a message as a memory, select it and click **Remember this**, or right-click it and choose **Remember this…**.

To copy a link from a message, right-click it and choose **Copy link**.

### Quote in reply

When Claude asks you something, you can answer each question under a quote of it. Select the text in a message and click **Quote**, or right-click it and choose **Quote** (**Quote message** without a selection, for the whole message). It goes at the end of the message box as a Markdown quote, `> ` before each line, with the cursor under it so you can type your answer. Quote the next question the same way and it lands after your answer. *Quote in reply* in the command palette quotes the selected text, or Claude's last reply when nothing is selected.

## Continue a past session

Open any session and type below it. If it isn't running, the message box says "Not running in Switchboard. Send a message to pick it up here." Sending picks the session up in Switchboard.

If the session is still open somewhere else, such as a terminal, Switchboard says so above the message box. Sending then starts a **fork**: a new session that continues from this conversation, leaving the original untouched. The send button says **Fork and send**.

## Agents and tools

- **Agents:** the agents Claude starts, background ones included, are under **⋯** in the header, with how many run ("2 running"). A dot on **⋯** says some are running. Choose **Agents** to see what each one is doing.
- **Tools:** the blocks button under the message box (or *Tools: MCP servers, skills, agents, plugins* in the command palette) opens the session's **MCP servers**, **Skills & commands**, **Agents** and **Plugins**. MCP servers show their status and tools; while the session runs in Switchboard, you can turn a server on or off, or reconnect it.

## The ⋯ menu

The **⋯** button in the header holds:

- **Open in** your editor, terminal or <Os mac="Finder" windows="File Explorer" /> (<Kbd shortcut="editor.open" /> opens the folder in your editor), and **Claude Code**, which opens the session in Claude Code's own terminal interface, in the terminal panel.
- **Continue in VS Code:** stops the session in Switchboard and opens it in Claude Code's VS Code extension, in the window for its folder. It shows when VS Code is installed, and waits until Claude is done. Also *Continue in VS Code* in the command palette.
- The project's [actions](/projects/actions/).
- **Profile** (with more than one Claude profile), **Rename…**, **Agents**, and **Check transcript…**, which explains why a conversation looks empty or short.
- **Memories from this session**, when Claude saved memories during it. Click one to open it in the editor.
- **Stop session:** ends the Claude Code process for this session. The conversation is kept, and sending a message starts it again.

<OnlyOn os="windows">

On Windows, **Open in** lists the editors whose command it finds (VS Code, VS Code Insiders, Cursor, Windsurf, Zed, Sublime Text, WebStorm and IntelliJ IDEA), Windows Terminal when it is installed, and File Explorer.

</OnlyOn>

With a session open, the command palette (<Kbd shortcut="palette.commands" first />) also has *Rename session…*, *Stop Claude*, *Copy session id*, *Reveal folder in <Os mac="Finder" windows="File Explorer" />* and *Delete session…*.

## Close a session

Click the **×** in the header (or *Close session* in the command palette) to go back to Home. A session that is working keeps running: pick it in the sidebar to open it again.

## Settings

- [Settings, Conversation](/settings/#conversation): **Summarised** (the default) shows each run of tool calls as one line; **Every step** shows each tool call as its own card.
- Each project's defaults for model, effort and mode are on its [Settings tab](/projects/settings/).
