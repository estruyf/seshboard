What you type in a message box and don't send stays there: in a session, and in New session. Seshboard keeps the text when you quit and brings it back next time, and shows you where your unsent messages are.

<Screenshot name="drafts" alt="The sidebar with a pen next to a session's age and its second line starting with Draft:, and the list of unsent messages opened from the 2 unsent pill in the footer" width={720} eager />

## Open it

- Click the **unsent** pill in the sidebar's footer ("2 unsent") for the list.
- Choose *Unsent messages…* in the command palette.
- <Kbd shortcut="palette.goto" /> lists them at the top, under *Unsent*.
- Home has an **Unsent** card. See [Home](/sessions/home/).

## What is kept

- **In a session:** the text in its message box, and the context chips.
- **In New session:** one prompt per project, with the model, effort, mode and route (current checkout or new worktree) you picked for it.

- **A new session that fails before it starts** (for example when Claude Code is not logged in): its first message. It is back in the session's message box, so you can send it again. If you quit first, it is in New session for that folder, with the choices you started it with.

Text is kept after you quit. Images you attached are kept while Seshboard runs, not after a restart; the message says how many weren't kept.

## Where it shows

- **In the sidebar**, a session with an unsent message has a small pen next to its age, and a pen on its icon in the minimal rail. When nothing else is going on there, its second line shows the start of the message after *Draft:*.
- **On the + button**, a pen means you have an unsent New session prompt, also one you typed for [another computer](/other-computers/). Clicking **+** then opens New session on that project, on that computer, with the prompt.
- **Above the message box**, a session you come back to says "Unsent message from 2 hours ago, kept for you.", with **Discard**.

## Find them all

Click the **unsent** pill in the sidebar's footer. The list shows every unsent message, newest first, with its session or project and the start of the text. Pick one (or use <Kbd keys="arrowup|arrowdown" /> and <Kbd keys="enter" />) to go there, with the cursor at the end of the text.

When you quit with unsent messages, the quit prompt counts them, with **Show unsent** to open the list instead of quitting. They are kept either way.

## When it goes away

An unsent message is removed when you:

- send it, start the session, or add the prompt to the [queue](/new-session/queue/);
- click **Discard**;
- delete the session.

Archiving a session with an unsent message asks first (*Archive and discard the unsent message?*), because archiving discards it.

<Aside type="tip">
Empty the message box (its text, images and chips) to drop an unsent message on the spot.
</Aside>

## Settings

Unsent messages have no settings. The quit prompt that counts them can be turned off with **Ask before quitting** in [Settings, General](/settings/#general).
