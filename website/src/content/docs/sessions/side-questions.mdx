A side question asks Claude about the session you are in, without adding anything to the conversation. Use it for "what was that flag again?" or "which file did you change for this?", also while Claude is busy with something else. Claude Code calls it `/btw`.

## Ask one

1. Type `/btw` at the start of the message box and a space, or pick **/btw** from the <Kbd shortcut="composer.commands" /> list. `/btw` turns into a blue token, and the box gets a blue frame.
2. Type your question.
3. Press <Kbd keys="enter" /> or click **Ask**.

The answer shows in a panel above the message box. In the command palette, *Ask a side question…* puts the token in the message box for you.

While the token is there, the message box asks instead of sending:

- <Kbd keys="enter" /> asks right away, also while Claude works. The question never waits in [Up next](/sessions/conversation/#up-next), and Claude isn't stopped or steered. The keys that would queue, steer or send now ask too.
- <Kbd keys="backspace" /> right after the token takes it out, and the box is a normal message again.
- Images and context chips in the box stay there for your next message.

## What Claude knows

Claude answers from the session's conversation, as it is at that moment, and from your earlier side questions in the session. It can't use tools: it doesn't read files, run commands or search. If the answer needs that, Claude says so; ask in the conversation instead.

Nothing of it changes the session: not the conversation, the title, the number of messages, its state in the sidebar or Up next. A side answer doesn't mark the session unread, and it doesn't play a sound or show a notification.

<Aside type="tip">
A session doesn't have to be running to answer. For a past session, or one that is open in another Claude Code window, Switchboard asks a short-lived copy of it, which writes nothing.
</Aside>

## The panel

The panel says **Side question** and *not in the conversation*. The question is its title, with the answer under it.

- **Answering** shows while Claude writes the answer.
- **‹** and **›** move through your earlier side questions in this session, with where you are ("2 of 3").
- **Copy** copies the answer as markdown.
- A long answer fades out under **Show all**, which shows the rest in the panel. The conversation doesn't move.
- <Kbd keys="escape" /> or **×** closes the panel. An answer that is still coming keeps coming: a chip above the message box says **Answering** or **Side answer ready**, with the question. Click it to open the panel again. The chip goes when you open the panel or send a message.

If a side question fails, the panel says why, with **Try again**. The error is never added to the conversation.

## Earlier side questions

Press <Kbd keys="enter" /> on `/btw` without a question to open the latest side question, then go back with **‹**. *Show side questions* in the command palette does the same, and shows how many there are.

Switchboard keeps the last 50 side questions of each session, also after you quit. Deleting a session deletes them too.

Before you have asked one, `/btw` without a question tells you how to ask one.

Showing earlier side questions needs Claude Code 2.1.212 or newer. With an older Claude Code, `/btw` needs a question, and the panel offers **Update Claude Code**. See [Updates](/settings/updates/).
