Seshboard is a desktop app for macOS, Windows and Linux for running and keeping track of your Claude Code sessions: you see which one works, which one waits for you and what each one changed. It uses the Claude Code you already have, with your own login, settings, commands and skills, so there is nothing extra to sign in to.

<Screenshot name="main-window" alt="Seshboard on a Mac with a finished session open: the sidebar with Needs you and Working groups on the left, the conversation in the middle and the Changes panel with a diff on the right" eager />

## Requirements

- A Mac with Apple Silicon, a PC with Windows 10 or 11 (x64 or Arm64), or a Linux computer (x64 or Arm64).
- [Claude Code](https://github.com/anthropics/claude-code) installed and signed in. If `claude` works in your terminal, you are ready. If it doesn't, Seshboard shows you how to install it when it opens; see [First launch](/getting-started/first-launch/#if-claude-code-isnt-installed).
- On Windows: [Git for Windows](https://gitforwindows.org), for Claude Code and for the [Changes](/terminal-changes-git/changes/) panel and [git](/terminal-changes-git/git/) features. PowerShell 7 is recommended; the Windows PowerShell every PC has works too.

<OnlyOn os="mac">

## Download the app

<Steps>

1. Download the `.dmg` from the [latest release](https://github.com/estruyf/switchboard/releases/latest).
2. Open it and drag **Seshboard** to **Applications**.
3. Open Seshboard from Applications or Spotlight.

</Steps>

Releases are signed and notarised by Apple, so macOS opens them without asking.

</OnlyOn>

<OnlyOn os="windows">

## Install on Windows

Download `Seshboard-<version>-setup.exe` from the [latest release](https://github.com/estruyf/switchboard/releases/latest).

<Steps>

1. Download `Seshboard-<version>-setup.exe`. It is one installer for x64 and Arm64 PCs: it installs the build that matches yours.
2. Run it. It installs for you only, in `%LOCALAPPDATA%\Programs\switchboard`, without asking for admin rights, and adds Seshboard to the Start menu and the desktop.
3. Seshboard opens when the installer is done. Later, open it from the Start menu.

</Steps>

If Windows SmartScreen says "Windows protected your PC", the installer isn't signed: see [If Windows blocks the installer](#if-windows-blocks-the-installer).

</OnlyOn>

## Install on Linux

Every release has an AppImage, a `.deb` and an `.rpm`, for x64 and Arm64. Download the one for your distribution from the [latest release](https://github.com/estruyf/switchboard/releases/latest).

- **Debian, Ubuntu and their derivatives:** install the `.deb` with apt, which also installs what it needs:

  ```bash
  sudo apt install ./Seshboard-<version>-amd64.deb
  ```

- **Fedora, RHEL and openSUSE:** install the `.rpm`:

  ```bash
  sudo dnf install ./Seshboard-<version>-x86_64.rpm
  ```

- **Any distribution:** make the AppImage executable and run it. It needs FUSE 2 (`libfuse2`, or `libfuse2t64` on Ubuntu 24.04).

  ```bash
  chmod +x Seshboard-<version>-x86_64.AppImage
  ./Seshboard-<version>-x86_64.AppImage
  ```

The `.deb` and `.rpm` add Seshboard to your applications menu. On Arm64 the files end in `arm64` (and `aarch64` for the `.rpm`). What works differently on Linux is in [Seshboard on Linux](/getting-started/linux/).

<OnlyOn os="mac">

## Install with Homebrew

If you use [Homebrew](https://brew.sh), install the cask:

```bash
brew install --cask estruyf/tap/seshboard
```

Seshboard updates itself, so `brew upgrade` skips it. To update it through Homebrew instead, run:

```bash
brew upgrade --cask estruyf/tap/seshboard
```

</OnlyOn>

## Build it from source

You can also build the app from the [repository](https://github.com/estruyf/switchboard). You need Node 24 or later, and it takes a couple of minutes. `npm run dist` builds for the system it runs on: a `.dmg` on a Mac, an installer on Windows, and an AppImage, `.deb` and `.rpm` on Linux.

```bash
npm install
npm run dist
```

<OnlyOn os="mac">

Then open `apps/desktop/dist/Seshboard-<version>-arm64.dmg` and drag Seshboard to Applications. A build you make yourself updates like a release.

</OnlyOn>

<OnlyOn os="windows">

### Build it on Windows

On Windows 10 or 11, run the same commands in PowerShell, with Node 24 and npm 11 or later, and Git for Windows. No Visual Studio build tools are needed. The build makes `apps\desktop\dist\Seshboard-<version>-setup.exe`; run it to install. A build you make yourself updates like a release.

</OnlyOn>

### Build it on Linux

Run the same commands with Node 24 and npm 11 or later, git, and the tools to compile a Node module (`build-essential` and `python3` on Debian and Ubuntu). The `.rpm` also needs `rpmbuild` (the `rpm` package on Debian and Ubuntu); without it the build makes the AppImage and the `.deb`. The files are in `apps/desktop/dist`.

<OnlyOn os="mac">

## If macOS blocks the app

A build you make yourself without a Developer ID certificate is unsigned. It opens normally on the Mac that built it. On another Mac, macOS blocks the first launch. Right-click the app and choose **Open**, or remove the quarantine flag in a terminal:

```bash
xattr -dr com.apple.quarantine /Applications/Seshboard.app
```

<Aside type="note">
The signed releases from GitHub and Homebrew don't need this. The [repository's notes on building and signing](https://github.com/estruyf/switchboard/blob/main/docs/building-and-signing.md) have the details.
</Aside>

</OnlyOn>

<OnlyOn os="windows">

## If Windows blocks the installer

An installer you build yourself is unsigned. On another PC, Windows SmartScreen stops it with "Windows protected your PC". Choose **More info**, then **Run anyway**. The [repository's notes on building and signing](https://github.com/estruyf/switchboard/blob/main/docs/building-and-signing.md#windows) have the details.

</OnlyOn>

## Uninstall

<OnlyOn os="mac">

Quit Seshboard and drag it from Applications to the Trash. With Homebrew, run `brew uninstall --cask estruyf/tap/seshboard`.

</OnlyOn>

<OnlyOn os="windows">

Open Windows **Settings › Apps**, find Seshboard and choose **Uninstall**. This also removes the `seshboard://` link handler Seshboard registered.

</OnlyOn>

On Linux, run `sudo apt remove switchboard` or `sudo dnf remove switchboard`, or delete the AppImage.

Your sessions stay in Claude Code's folder, and Seshboard's own data (projects, actions, preferences) stays in <Os mac="~/Library/Application Support/Seshboard" windows="%APPDATA%\Seshboard" />. On Linux it is `~/.config/Seshboard`. Delete that folder too if you don't want to keep it.

## Updates

Seshboard checks for a new release shortly after it opens and every few hours, and tells you in the corner of the window when there is one. It also checks whether the Claude Code it runs is up to date. See [Updates](/settings/updates/) for how it works and how to change it.

## Settings

The update checks and the update channel are in [Settings, About](/settings/#about). Open Settings with <Kbd shortcut="settings" />.
