## LinkedIn

Switchboard 0.0.14 is out, and it's the biggest release so far. The headline: Switchboard now runs on Windows.

Switchboard is my desktop app for running Claude Code sessions side by side. Until now it was Mac only. From this release there's a Windows installer for x64 and Arm64 that installs without admin rights and updates itself, with PowerShell in the terminal and Ctrl shortcuts.

What else is new:

• Memory management. Edit Claude Code's memory in a project's Memory tab, follow links between memories, see what loads at the start of a session, and get a health check for stale references, duplicates and an index that's too long.
• Share with the team. Turn a private memory into CLAUDE.md or a rule file, with a preview before anything is written.
• Personal memory that loads in every project, and import from the Claude app.
• A page for each project, with Overview, Sessions, Worktrees, Branches and Memory tabs.
• Branch and worktree overview. See what's merged, pushed or stale, and clean up the ones you're done with in one go. Nothing with uncommitted work or an open pull request is ever removed.
• Answer permission prompts and questions from VS Code with the companion extension.

And there's a new website with the docs for every feature, setting and shortcut, on Mac and Windows: https://switchboard.struyfconsulting.com/

Switchboard is free and open source. Let me know what you think.
