## LinkedIn

Switchboard 0.0.23 is out, with two features I like a lot.

Saved prompts. Most of us type the same kinds of prompts over and over: fix this issue, review that pull request, write the release notes for a branch. Now you save them once, with blanks. Type / in any message box and your saved prompts come first. Pick one, and each blank becomes a chip: pick a GitHub issue, an open pull request, a branch, a file or one of your own options, Tab to the next one, and send. Keep them for every project, for one project, or share them with the team in the project's .switchboard.json.

What your tokens cost. Your plan isn't billed per token, but it helps to know what you're using. Switchboard now shows what the tokens of each 5-hour and weekly window would cost at Anthropic's API prices, and what each session has used so far, in the currency you pick. The Usage view breaks it down per session, project, model and day.

It also warns you about the expensive moment: when a large context's prompt cache is about to expire, a note says when, and what your next message would cost after that, with Compact now.

Also new:

• Start a project from a GitHub URL: Switchboard clones it, adds it and starts the session.
• See a pull request's checks on the git button, and let Claude fix the ones that fail.
• Open a session in its own window, next to the main window or on another screen.

Switchboard is free and open source, for macOS and Windows: https://switchboard.struyfconsulting.com/
