## LinkedIn

Switchboard 0.0.21 is out, and it closes a loop most of us still do by hand.

Claude suggests a command, you run it, then copy the output and paste it back so Claude can see what went wrong. Not anymore:

• Run and send. A shell block in Claude's reply now has "Run and send the output to Claude". The command runs in its own terminal tab, and when it ends Claude gets the command, its exit code and the end of its output, so it carries on by itself. Project actions can do the same, for a Test or Lint action whose result Claude should see.
• Commands panel. The commands Claude runs in the background, like a build or a dev server, now have their own panel next to Changes, Ask and Agents: what runs, how it ended, and the output live, with Copy and Stop.

Also new:

• Claude Code mods show in Switchboard: bands above the message box, panes, statuses and toasts, each in your theme's colours.
• Usage adds up the tokens of the same Claude account across the computers you paired.
• See which phones and computers are connected to this Mac, with what they did last, and revoke one.
• On another computer you can now pick the branch, profile, model, effort and mode before a session starts there.

Switchboard is free and open source, for macOS and Windows: https://switchboard.struyfconsulting.com/
