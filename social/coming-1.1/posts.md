## LinkedIn

A first look at Switchboard 1.1, which is in beta now. The theme of this release: Claude Code that starts on its own.

Until now, every session started with you typing a prompt. In 1.1, Switchboard can start the work for you:

• Scheduled sessions. Run a prompt once, every day, on weekdays, on set days each week or on a day each month. A morning triage of new issues, a weekly dependency update.
• Triggers. Start a session when CI fails on a branch, or when an issue is labelled or assigned to you. Switchboard checks through the GitHub CLI and never bypasses your permissions.
• Pipelines. Run a saved set of steps for one task, each in its own sub-session: plan with one model, build with another, let a fresh session check the work, then push. The steps hand over to each other with @ links.
• Queued items that start by themselves when the session they wait for finishes cleanly.
• Upcoming. One view for everything queued and scheduled, across all your projects, with the next 7 days and a history of how the runs went.

Also coming in 1.1: Switchboard on Linux, # to attach a GitHub issue or pull request to a message, previews of Markdown, HTML and code files, a reading mode, and nine app icons with themes to match.

Want to try it before the release? In Switchboard, go to Settings › About and pick the Beta channel, or download a beta from GitHub: https://github.com/estruyf/switchboard/releases

Feedback on the betas is very welcome.
