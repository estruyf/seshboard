## LinkedIn

Switchboard 1.0 is out. 🎉

Two weeks ago I made the first commit. 24 releases later, it's 1.0.

Switchboard is a free, open-source desktop app for Mac and Windows that puts all your Claude Code sessions in one window. It runs on the Claude Code you already have, with your own login, settings, skills and MCP servers.

What you get:

• Every session in one list, the ones in your terminal too, with what needs you on top.
• Several Claude accounts side by side, like a personal plan and a work one, and the sessions of your other computers in the same view.
• Switchboard Remote: allow, deny and answer Claude from your phone, end-to-end encrypted.
• A catch-up when a session finishes: what it needs from you, whether the tests passed, and how much changed.
• Saved prompts with blanks for an issue, a pull request or a branch.
• What your tokens would cost at API prices, per window, session and model.
• Worktrees per task, pull request checks, a Commands panel, Auto model and a lot more.

New in 1.0: link another session with @ so Claude can build on its branch and pull request, use Claude in Chrome in your sessions, a Beta channel to try what's next, and signing in to a new Claude profile right inside the app.

Thank you to everyone who tried it and sent ideas along the way. If you run Claude Code, give it a try, and let me know what you think.
